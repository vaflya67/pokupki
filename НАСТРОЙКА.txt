СИНХРОНИЗАЦИЯ — НАСТРОЙКА (один раз, ~5 минут)
============================================

Чтобы список был общий у тебя и у девушки, нужен бесплатный Firebase.
После настройки оба открываете одну ссылку — изменения видны сразу.

ШАГ 1. Firebase
---------------
1. Зайди на https://console.firebase.google.com
2. «Создать проект» → любое имя (например spisok-pokupok)
3. Google Analytics можно выключить
4. Проект → шестерёнка → «Параметры проекта»
5. Прокрути вниз → «Ваши приложения» → иконка </> (Web)
6. Имя приложения: spisok-pokupok → «Зарегистрировать»
7. Скопируй объект firebaseConfig

ШАГ 2. Файл конфига
-------------------
1. Скопируй firebase-config.example.js → firebase-config.js
2. Вставь свои ключи вместо YOUR_...

ШАГ 3. Firestore (база данных)
------------------------------
1. В Firebase: «Firestore Database» → «Создать базу»
2. Режим: «Начать в тестовом режиме» (потом заменим правила)
3. Регион: europe-west (ближе к Украине/России)
4. «Правила» → вставь содержимое файла firestore.rules → «Опубликовать»

ШАГ 4. Залить в интернет (GitHub Pages — бесплатно)
---------------------------------------------------
Netlify тоже можно, но если лимит — GitHub:

1. Зайди на https://github.com → войди в аккаунт
2. «+» → New repository
3. Имя: spisok-pokupok → Public → Create repository
4. «uploading an existing file» → перетащи ВСЕ файлы из папки
   (index.html, app.js, style.css, firebase-config.js и остальное)
5. Commit changes
6. Settings → Pages → Source: Deploy from branch
7. Branch: main → Folder: / (root) → Save
8. Через 1–2 мин сайт: https://ТВОЙ_НИК.github.io/spisok-pokupok/

Альтернатива: https://app.netlify.com/drop — перетащить папку

ШАГ 5. Подключить девушку
-------------------------
1. Ты: «Создать список» в приложении
2. Нажми «Поделиться» — отправь ей ссылку в Telegram/WhatsApp
3. Она открывает → тот же список, синхронизация автоматом

Код списка — 6 букв/цифр. Кто знает код или ссылку — может редактировать.
Для списка покупок это нормально. Не свети код посторонним.

Локально без Netlify: открывай index.html только для проверки.
Для синхронизации между двумя телефонами нужен HTTPS (Netlify бесплатно).
